添加后的代价：

需要一条新迁移把 CHECK 收窄为不含 spv（当前 0 行，无数据迁移；历史迁移 V354 本身不改）；新迁移版本号受 complex_test 已应用未发布 V400–V409 的环境漂移影响，须操作员同时裁定版本号（见 findings M010-009）。不会失去任何现有业务能力（backend/src/main/java 0 处引用 spv）。建议删除。
