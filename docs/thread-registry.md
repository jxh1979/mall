## 维护规则

1. 一个专项线程只处理自己的范围。
2. 跨模块问题先回到主线程协调。
3. 如果专项线程产出数据库表、接口或页面设计，需要同步更新项目文档。
4. 代码实现优先在 Java后端、前端管理后台、安卓设备端、运维部署这些工程线程里推进。
5. 重复线程建议后续归档，避免同一专项多处维护。
6. 本表为唯一权威；旧线程索引三件套仅作历史，不再据其线程 ID 进入会话。
