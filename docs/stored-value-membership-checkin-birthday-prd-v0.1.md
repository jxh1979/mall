## 1. 储值（余额钱包）

- 客人按**卡类型**开储值账户：综合体级（全场通用）或商户级（仅该商户），隔离按账户自带 scope。
- 动作：充值（topup，走支付意图）、消费（consume，幂等键防双花）、结算（settle）；
  平台侧可冻结 / 解冻 / 退款（退款受商户退款规则约束，每综合体各管各）。
- 余额只能来自真实充值与退款回冲；所有动作落审计与短信通知（充值 / 消费两事件，三级开关）。
- 客人端 WalletPage 只读展示余额与流水；账号进入封禁 / 黑名单 / 注销状态即不可用（V194 状态闸）。

## 2. 付费会员（订阅）（已废止 2026-07-18）

> **[已废止 2026-07-18]** 付费会员（客人付费购买年卡/权益包）已按权威业务地图（三份业务 HTML 对「付费会员」零命中）彻底废除：客人端/后台端点、`customer_memberships` / `customer_membership_plans` 两表、`MembershipService`、OpenAPI 六条 operation 全部下线（迁移 V290 DROP 两表并退役 `customer.membership.*` 三条权限）。本节仅存历史记录，非现行能力；免费会员忠诚度（成长积分/等级自动升级）与储值预付卡不受影响。

- 会员 = 客人购买的付费计划（plan），有起止期（start_at / expire_at）与自动续费标记（auto_renew）。
- 关联支付意图（payment_intent_id）；是否到期自动续扣由后台配置项 **auto_renewal.enabled（默认关）** 控制：默认关时到期不自动扣款；支付网关接入后，可按项目 / 会员计划维度启停自动续扣，不写死为永不扣款。
- 会员身份用于价格派生（member 人群派生价，见票务策略）与权益展示；客人端「储值 / 会员」页展示。

## 3. 连续签到

- 客人每日一次签到（幂等：同日重复签到不重复计），连续天数累计，中断归一。
- 奖励：按连续天数发积分（当前 +10 积分/次基线），入成长积分与可用积分两本账（keep_threshold_progress）。
- 端点仅客人本人 token 可用；来源终端留痕（source_terminal）。

## 4. 生日权益

- 项目级生日规则（CustomerBirthdayRule）：规则名 / 窗口类型（生日当天 / 当周 / 当月）/ 积分倍数
  （basis points，如 20000=2 倍）/ 状态。
- 客人生日信息来自实名 / 登记的 birth_date；命中窗口期间消费积分按倍数放大。
- 规则平台可配可停用；每综合体各配各的。

## 5. 边界与不做

- 不做储值转赠（已下线的孤儿能力，勿复活）；不做积分换现金；
- 会员自动续扣、储值在线支付通道依赖第三方支付接入（预留接口 + 开关默认关范式）。

## 6. 权威与追溯

- 库表：V089（会员等级 / 积分）、V090（储值 / 付费会员 / 转赠下线）及后续迁移；
- 代码：MemberWalletController / LoyaltyController / CustomerController（check-ins、memberships）；
- 与积分两本账口径见审计 V2 裁决（keep_threshold_progress=成长积分，仅命名差异）。
