# 管理台页面结构优化记录

更新时间：2026-06-05

## 优化结论

管理台已从单层功能菜单调整为多级目录结构，便于后续继续接入 P1/P2 模块时保持清晰的信息架构。

## 多级目录

左侧目录分为四组：

- 总览
  - 控制台
- 业务运营
  - 票务核销
  - 酒吧经营
  - 游乐运营
- 平台治理
  - 平台地基
  - 第三方接口
  - 风控预警
  - 事件留痕
- 分析决策
  - 经营看板

## 内容区结构

内容区新增统一页面头：

- 面包屑：展示当前页面所属目录和页面名称。
- 页面标题：随当前页面切换。
- 页面摘要：帮助区分同类运营模块。
- 同组切换：在业务运营等多页面目录下，可快速切换同组子页面。

## 后续建议

下一阶段可把每个大模块继续拆成三级目录，例如：

- 酒吧经营：开台点单、库存存酒、出品预订、经营报表。
- 游乐运营：项目场次、预约排队、设备巡检、故障处理。
- 第三方接口：开放应用、餐饮零售、机器人、视频监控、企业微信、设备接入、对账补偿。

> 修订说明（2026-06-07）：本记录只覆盖 `apps/web` 管理台（平台端）目录结构。除平台端/商户端/看板外，前端还新增"移动管理端"响应式工作台（管理概览、待办中心、异常详情、审批复核，移动审批对齐 P0），其路由组、页面与 API 映射见 `frontend-admin-development-design.md §3.6/§5.1/§7.11`，对应基准 D5 终端枚举 `mobile_admin`（依据 finding webmobile-4、D5）。本菜单结构后续接入 P1/P2 时也应保留与该工作台一致的信息架构口径。
