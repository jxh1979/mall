## 3. 使用规则

- 总体方向、跨系统边界、优先级和是否开始编码，放在主线程。
- 单个系统的详细设计、表结构、接口、页面和实现，放到对应专项线程。
- 专项线程如果发现跨系统问题，先记录问题，再回到主线程决策。
- 不同专项线程不要同时修改同一批核心文件，避免冲突。
