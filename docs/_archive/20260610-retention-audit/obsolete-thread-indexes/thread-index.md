## 3. 使用建议

- 涉及跨模块决策时，先回到主线程讨论。
- 明确属于某个领域的细化和开发，进入对应专项线程。
- 每个专项线程都应优先阅读相关 `docs/` 文档，再继续设计或编码。
- 如果某个专项需要动代码，先确认是否会影响其他专项，再在主线程同步。
