## Behavior Covered

- Permission dictionary seeded for P0 `access.*` and `ops.production_readiness.*` permissions.
- Permission calculation enforces:
  - fail-closed missing permissions
  - `PERMISSION_DENIED` with HTTP 403
  - deny-over-grant precedence
  - expired temporary template grants ignored
  - single-use template grants consumed after first successful authorization
  - `platform_admin` seed bridge only, not arbitrary staff bypass
- Access API implements the existing `/api/v1/access` contract paths:
  - permission templates: list/create/update/apply/copy
  - permissions: list
  - roles: list/create
  - temporary grants: create/revoke
  - users: list/create
- Write operations go through `IdempotencyService`.
- Access operations write audit events through `AuditEventService`.
- JDBC timestamptz writes use UTC `OffsetDateTime` conversion, following existing repository patterns.
