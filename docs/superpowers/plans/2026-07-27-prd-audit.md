# 综合体管理系统 PRD 全量审计实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以三个现行业务 HTML 为最终解释权，对远端仓库全部现行 PRD及直接相关文档完成可追溯的顺从性、对抗性和第一性原理审计，并把每个阶段的获批修订经 PR 合并到 `main`。

**Architecture:** 先锁定审计范围和历史续接基线，再把三个 HTML 拆成原子规则账本；随后按四组业务域审计 PRD，最后执行跨域一致性收口。每个阶段使用独立分支和 worktree、独立 `npm ci`、独立验证与 PR；远端 `main` 是唯一最终版本。

**Tech Stack:** Git worktree、GitHub CLI、Node.js 22、npm/package-lock、Markdown、CSV、PowerShell（本机副本）、Bash（远端执行）。

## CSV 接口

### `document-scope-manifest.csv`

固定列：

```csv
path,document_type,domain,status,authority_role,reason,sha256
```

`status` 只允许 `INCLUDED`、`EXCLUDED`。`authority_role` 只允许 `FINAL_HTML`、`PRD`、`PRODUCT_SPEC`、`DECISION`、`TERMINOLOGY`、`TRACEABILITY`、`INDEX`、`HISTORICAL_EVIDENCE`、`OUT_OF_SCOPE`。

### `authority-rule-ledger.csv`

固定列：

```csv
rule_id,html_file,anchor_or_line,source_text,domain,subject,object,trigger,preconditions,state_transition,value_flow,permission,approval,separation_of_duties,failure_recovery,evidence_required,decision_status
```

`rule_id` 前缀按来源固定为 `BSM-`、`PGM-`、`BEQ-`；编号为四位十进制，如 `BSM-0001`。`decision_status` 只允许 `AUTHORITATIVE`、`NEEDS_DECISION`、`DECIDED_BY_USER`。

### `html-prd-coverage.csv`

固定列：

```csv
rule_id,prd_path,prd_anchor_or_line,coverage_status,severity,finding_id,conflict_summary,recommended_change,decision_id,phase
```

`coverage_status` 只允许 `FULL`、`PARTIAL`、`CONFLICT`、`MISSING`、`AMBIGUOUS`、`STALE`、`NOT_APPLICABLE`。`severity` 只允许空值、`P0`、`P1`、`P2`、`P3`。
