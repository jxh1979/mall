综合体管理系统 · 业务枚举速查表

V0.1 ｜ 2026-06-23 ｜ 给业务同事快速查“系统支持哪几种 / 有哪几个状态 / 按什么规则”。状态枚举为业务口径，最终以后台配置为准。

用法：左列是“问题”（如“账单有哪几个状态”），右列是“答案”。配套两份业务地图（业务系统地图 / 平台治理地图）使用。

一、票务与权益

票种平日票、周末票、节假日票（基础价）；成人票、学生票；多人票（双人 / 团队）；新人票；会员价、渠道价、动态价；一人多次票、通票
通票类型酒吧通票、游乐通票、酒吧+游乐联合通票、含餐饮/零售优惠折扣的组合通票
权益类型入场、游乐、酒水（赠饮/兑换券）、卡座免通票入场名额、餐饮券、零售券、服务权益、积分兑换礼物
餐饮/零售券两种用法折扣型（享优惠、不用逐张回传）、券核销型（持券到第三方核销、需逐张回传）
资格判定新人（按手机号自动判）、学生票（人工审核+学信网）、多人票（同一时段一次性全部核销）、一人多次票（一人多次入场，首次核销后绑定使用人，仅本人续用）
订单状态待支付、已支付、已出票、部分核销、已完成、退款中、部分退款、已全退、已取消、已关闭、异常
票/权益状态未使用、部分使用、已使用、已过期、已退款、已作废
核销记录状态预检通过、成功、拒绝/失败、人工放行、已冲正、待复核、异常
退款单状态已申请、审批中、已通过、已驳回、处理中、成功、失败、已取消
有效期类型永久 / 固定天数 / 按自然年
退款规则未使用可退；同一票有一张核销则整票不可退；权益到期：全未核销自动退款、有核销则其余作废

二、会员与积分

会员等级按累计成长积分自动升级；成长积分只增不减、仅到期清减，清减后等级才可能下调
积分两本账成长积分（算等级，只增不减、仅到期清减、不受兑换影响）；可用积分（兑换消耗会扣减、不影响等级）
积分获取方式有消费就给：按消费金额 / 按核销张数（购票一次送固定值）/ 签到打卡 / 生日加赠 / 活动
积分获取渠道关联微信/支付宝后付款自动累计；POS、现金等可现场录会员号累计
积分明细类型获取、扣减、兑换消耗、过期、调整
积分过期方式成长积分按自然年清零，或按后台配置的有效天数清零
兑换发放状态待发放、已发放、已取消、异常
会员忠诚度扩展连续签到、生日加倍；储值预付卡、付费会员订阅

三、酒吧经营

订台定金状态未支付、已支付、到店已抵扣、已退还、已没收
点酒方式按杯、按瓶、套餐（按杯按标准出酒量扣库存、超出记损耗）
支付方式客人扫码、扫客人付款码、现金（记收款人）、POS（记流水号+收款人）
销售提成销售人员卡座 15%、非销售 10%；不计提成：通票、票务权益、卡座入场名额、赠送成本、退款、免单
退菜退酒出品前撤单（不计损耗）、出品后退品（按是否回库处理）；高价值退酒走退款冲正+证据+主管审批

出品票据状态待接单、制作中、已备好、已送达、已取消、异常；仅卡座点酒/扫码点单与后厨自营出品走此流转，吧台直点即点即取不走，独立餐饮商户走第三方
账单操作拆单（分开支付）、合单（同酒吧并台）
收银交班状态开班、待交班、已交班对账、有差异待复核、已平账
小费结账可录小费（额/比例），入账单、归属服务员、进交班对账；不计入低消与提成基数
