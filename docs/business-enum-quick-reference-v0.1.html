V0.1 ｜ 2026-06-23 ｜ 给业务同事快速查“系统支持哪几种 / 有哪几个状态 / 按什么规则”。状态枚举为业务口径，最终以后台配置为准。

用法：左列是“问题”（如“账单有哪几个状态”），右列是“答案”。配套两份业务地图（业务系统地图 / 平台治理地图）使用。

一、票务与权益

票种平日票、周末票、节假日票（基础价）；成人票、学生票；多人票（双人 / 团队）；新人票；会员价、渠道价、动态价；一人多次票、通票
购票渠道主路径：客人通过官方 App/小程序或第三方平台自助购买；客人可在自己手机上的综合体官方小程序或 App 自助购买该酒吧单店门票；例外：授权服务人员在启用售票能力的一体机上辅助到店客人购票。综合体通票只能由项目公司售卖（官方 App/小程序或授权第三方渠道），商户门店与酒吧门口/前台一体机都不得售卖通票；单店门票可由授权售票一体机代售本酒吧门票。
通票类型酒吧通票、游乐通票、酒吧+游乐联合通票、含餐饮/零售优惠折扣的组合通票
权益类型入场、游乐、酒水（赠饮/兑换券）、卡座免通票入场名额、餐饮券、零售券、服务权益、积分兑换虚拟券
餐饮/零售券两种用法折扣型（享优惠、不用逐张回传）、券核销型（持券到第三方核销、需逐张回传）
资格判定新人（按手机号自动判）、学生票（人工审核+学信网）、多人票（同一场次内核销、同场次内不同人可分别入场）、一人多次票（一人多次入场，首次核销后绑定使用人，仅本人续用）
订单状态待支付、已支付、已出票、部分核销、已完成、退款中、部分退款、已全退、已取消、已关闭、异常
票/权益状态未使用、部分使用、已使用、已过期、已退款、已作废
核销记录状态预检通过、成功、拒绝/失败、人工放行、已冲正、待复核、异常
退款单状态已申请、审批中、已通过、已驳回、处理中、成功、失败、已取消（退款以“成功”为最终完成态，只有“成功”的退款才计入“已退金额”；“已通过”表示已批准并已发起不可逆兑付。）
有效期类型永久 / 固定天数 / 按自然年
退款规则按票实例判断：未核销一人票可按张退；已核销一人票不可退；多人票/多次票任一权益或门票已核销则该票整张不可退；同单其他完全未核销票仍可退
通票分账全流程通票收入 → 先扣第三方渠道抽成 → 再扣赠酒成本 → 进可分配池 → 项目公司留存（默认 20%、可配） → 各酒吧总池 → 各酒吧按“排名档位 / 每客单价 / 固定额”三选一分配；各酒吧分得总额不超总池，突破上限仅限平台负责人特批的短期激励（≤3 个月）
通票赠酒两段结算第一段：每核销一杯先留 3 元酒成本补偿酒吧（没核销不留）；第二段：剩余按各酒吧协议（每客单价 / 排名档位）分给酒吧
通票结算口径按客人实际核销逐笔结算（非买了就结）；未核销的权益那部分钱归项目公司留存；结算与权益归属分开
门票综合服务费所有门票项目都收一道综合服务费/项目管理费，按比例或固定额、项目与商户洽谈后台可配，用于覆盖统一售票/结算/平台运营，归项目方；可按范围另设每月封顶，默认不封顶

二、会员与积分

会员等级按累计成长积分自动升级；成长积分只增不减、仅到期清减，清减后等级才可能下调
积分两本账成长积分（算等级，只增不减、仅到期清减、不受兑换影响）；可用积分（兑换消耗会扣减、不影响等级）
积分获取方式有消费就给：按消费金额 / 按核销张数（购票一次送固定值）/ 签到打卡 / 生日加赠 / 活动

积分明细类型获取、扣减、兑换消耗、过期、调整
积分过期方式成长积分按自然年清零，或按后台配置的有效天数清零
兑换发放状态待发放、已发放、已取消、异常
积分兑换口径积分只兑虚拟券、不直接兑实物；兑换当时不减可售库存（实物券当场从可用库存预占冻结一件、发券受可用库存约束以防超发）
券三类①商户折扣券（到对应商户抵扣，不涉及库存）；②店内实物/服务（发券时从可用库存预占，到店由店员核销领取时才实扣、按内部结算价与承接商户结算，券过期作废释放预占）；③平台或外部合作伙伴（到平台服务台或外部合作伙伴处核销）
券状态与规则客人「我的券包」按可用 / 已核销 / 已过期分组只读；券可设有效期、过期不退；券是否可转赠在后台生成券种时可配置，默认可转赠、关闭则该券种发出的券不可转赠；换实物的券若实物缺货可退回成积分；券对应的内部成本价对客人和店员均不可见
会员忠诚度扩展连续签到、生日加倍；储值预付卡
