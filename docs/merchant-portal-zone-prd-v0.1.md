## 1. 背景与定位

- 商户（租户 / 联营方 / 服务商）当前依赖平台侧人工传达账单与工单进展；已有 ADM-MER-002「商户授权工作台」
  承载平台给商户账号授权的一侧，商户自助的一侧缺正式口径。
- 本专区定位：**商户自助查看与自助发起**，不改变三份业务 HTML 及已批准资金／审批流程确定的责任边界。

## 2. 商户账号与数据边界

- 商户账号 = 既有员工账号体系中 `merchant` 归属账号（access_users.merchant_id），登录入口与平台员工相同。
- 数据边界铁律：**只见本商户**——账单 / 工单 / 对账 / 合同均按账户自带 merchant scope（`access_users.merchant_id`）过滤（复用
  currentMerchantScope 既有管道）；跨商户读一律拒绝并留审计。当前实现的商户隔离键为 `merchants.business_entity_id`；“我的合同”按 `contracts.merchant_id` 命中本商户，主体／铺位关系细节见 `merchant-space-contract-model-v0.1.md`。该实现模型不得覆盖三份业务 HTML。
- 终端管控：受 `merchant_portal` 终端总开关与模块开关约束，关闭即不可用（前端隐藏 + 后端拒绝）。

**我的证照（待建·实现待对齐；依据 PGM「管理证照、资质、保险和合同关键日期的到期预警与到期阻断」条）**
- **能力**：商户在专区可查看**本商户全部证照/资质/保险的到期情况**——清单 + 到期预警 + 宽限期状态，**只读**（申请宽限期、上传换证材料等写动作不在 P0 范围）。
- **规则**：到期预警**一律提前发出**（业务参数，**按证照类型可配**，出厂默认提前三个月，须同时配置上下限），且**预警同时送达商户侧**；到期后可申请**后台可配时长的宽限期**（业务参数，按证照类型可配），**宽限期须经最高权限审批后生效**，宽限期内可继续经营但**每日提醒**，**超过宽限期仍未更新的一律阻断、不得再次延长**——专区只**如实展示**该状态，审批与阻断均在平台侧执行。
- **现状**：平台侧有合规到期域（V028 `compliance_expiry_items`/`contract_key_dates` + `/api/v1/compliance/*`），**但无商户侧只读视图、无商户专区页面**（`adminRoutes` 商户专区仅 ADM-MER-003..008）；**本轮只登记口径与缺口，不建页面、不改代码**。

**商户异议规则（2026-08-04 对齐 BSM「商户提出的投诉与异议，与客人投诉并入同一通道」条）**
- **同一通道**：商户提出的投诉与异议，**与客人投诉并入同一通道，由客户关怀部统一受理**，不区分对客与对商户；专区「我的对账」的异议留言即进入该通道。
- **异议范围铁律**：**商户只能就数字提出异议——包括漏算、少算、多算；不得对规则本身提出异议，规则以合同约定为准**。
- **付款义务不暂停**：**提出异议期间商户的付款义务不暂停，先按原值付款，异议成立后多退少补**。

**酒吧商户异议的处理口径（2026-08-05 R7 第三批用户裁决改写，依据 PGM「独立酒吧商户」条 / DIFF-B-019）**
- **受理人**：**独立酒吧商户提出的异议，由客户关怀部协调处理**——经**内部工单流程**流转至相关部门处理，**处理结果反馈商户，并必须形成完整闭环**（未闭环的工单不得关闭）。通道入口不变（专区「我的对账」异议留言进入统一通道），与上述客户关怀部通道**为同一通道、同一受理主体**。**原「由城市项目公司与顶层平台组成的联合裁决人受理并出具书面结论」的专属裁决主体口径已于 2026-08-05 用户裁决作废、不再适用。**
- **处理时限**：须在后台配置的处理时限内给出处理结果并闭环——**业务参数，按项目可配，出厂默认二十个工作日，须配上下限**。该时限与 §3「异议期」（商户可提出异议的期限，默认 10 个工作日）是**两个不同的参数**：异议期约束商户何时可提，处理时限约束平台何时须给结论。
- **处理期间照常结算**：**处理期间按原有效数值先行结算**；**结论生效后按差额补退**——不因异议挂起而暂停出账、也不因处理未决而重算历史账期。
- **可异议范围不变**：酒吧商户同样只能就数字（漏算、少算、多算）提出异议，**不得对规则本身提出异议**；酒吧商户**不能自行决定酒吧通票域内分配方式**，只能提交价格资料、履约事实与异议。

**异议期口径（2026-08-04 对齐 BSM「给商户」条）**
- **适用范围**：适用于**非积分类的商户账单**（房租、水电、物业、结算金额出账与调整、押金、违约金、分红）；**积分结算账单的账期与异议期由全国积分结算中心统一规定，两者互不包含**。
- **起算**：异议期**自该账单在商户专区可查看之日的次日起算**；长度由后台配置（业务参数，按项目可配，**出厂默认 10 个工作日**）。
- **提醒不影响起算**：**短信与商户手机应用推送均为提醒手段，发与不发、成功与否都不影响异议期的起算与届满**。
- **不可用日不计入**：**商户专区不可用的自然日不计入异议期**，以平台的**门户可用性记录**为准。
- **不顺延**：**商户在异议期内未登录的，异议期不顺延**；**商户专区首页保留未读账单提醒，该提醒不因异议期届满而消失**。
- **押金退还不适用本异议期（2026-08-06，DEC-R8-13）**：押金退还支付**以退租结算算账完成为准、且不早于等待期届满**（等待期自最后一个审批完成之日起算，业务参数，按项目可配，出厂默认 30 日），**不受三个付账日与账单异议期约束**；商户对退租结算金额的异议**在退租审批流程中提出并解决**，不走本节异议流程。**算账晚于等待期完成的，顺延至算账完成之日支付；顺延原因与预计时间在商户专区对商户可见**（依据 BSM「变更与退租」条、ENUM「退租结算状态」条）。
