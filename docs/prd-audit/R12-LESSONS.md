# R12 轮方法论与结构性发现

> 基线 `b489abd2`(PR#353~#358 全部合并后)。本文件每条结论均附本轮实证,可复核。
> **凡计数断言必须附取数命令与命中数** —— 否则下一轮读者无从判断它是实测还是转述。

## 一 · 测量方法会静默失效(五类,全部本轮实证)

失效的表现**永远是「通过」**,不是报错。凡预期红却报绿、或数字对不上,先怀疑测法。

| # | 失效形态 | 实证 | 规避 |
|---|---|---|---|
| 1 | **注入没生效** | `perl -i -pe 'if (/^BSM-0011,/)'` 注入 —— 账本每字段带引号、行首实为 `"BSM-0011",`,正则从未匹配,文件没变,门禁仍绿 | 注入后先验 `sha256` 变了、`grep -c 注入串 > 0`,再看门禁 |
| 2 | **heredoc 被 shell 展开** | python 压根没执行,文件没变,`EXIT=0` 无效 | 脚本首行打印 SENTINEL,看到才算跑过 |
| 3 | **管道吃退出码** | `npm run X 2>&1 \| tail -N; echo $?` 取的是 `tail` 的码,**永远 0** | `${PIPESTATUS[0]}` 或不带管道重跑 |
| 4 | **抽样有系统性盲区** | `step = N//40` 只走到 idx 585,尾部 44 条永不抽到(恰是 finance 段末尾);改覆盖全域后第 15 条即命中假阴性 `BSM-0420` | `idx = round(i*(N-1)/(k-1))` 覆盖首尾 |
| 5 | **样本量与基数脱钩** | 覆盖率落差 16 倍(finance 21 抽 15=71%,governance 113 抽 5=4.4%);按 finance 命中率反推,governance 抽 5 条恰好全错过概率约 87% | `max(5, ceil(n×15%))`;governance 5→17 才抽到 `BSM-0547` |

**第 6 类:解析器自身缺陷** —— 汇总验真时首版解析器未去反引号致 S4 解析出 0 行、未限章节致 S3/S7 把后续表格计入。**正确归因是「测量失效」不是「被测对象失真」。**

## 二 · 三个在本工作流下自证无效的检查

| 检查 | 为什么恒定失效 | 正解 |
|---|---|---|
| `git branch --merged` 判分支已合并 | squash 生成全新提交,原分支提交**永不是 main 的祖先**,对任何 squash 分支恒返回 0 —— 不是「未合并」信号,是恒假谓词 | 查 `gh pr view` 的 merged 状态,不查 ancestry |
| `verify:html-ledger-sync` / `verify:html-param-tier` 的「本次未改动 HTML」 | 比对范围是提交区 `origin/main...HEAD`,**未 commit 时该范围为空集**,对工作区改动是瞎的 | 以 `git diff --exit-code <BASE> -- <三份HTML>` 为准,门禁那句只作旁证 |
| `verify-entry-anchors` 对 `rounds/**` 产物 | `EXCLUDE` 含 `[\\/]rounds[\\/]`,该目录全部文件不在被检面内 | 该目录产物不受门禁保护,不得拿 `EXIT=0` 当质量证据 |

## 三 · agent 报告可能整份虚构

**实证**:G-1 S7 曾返回两份内容冲突的报告 —— 判定分布、dividend 计数、钱路条目名、行数全不同。
实测产物 118 行:第一份提到的 `BSM-0416`/`0417`/`0421`/`0265` **在文件里零命中**;第二份提到的 `BSM-0411`/`0413`/`BEQ-0117`/`BEQ-0121`/`BSM-0786` 命中 3/3/2/3/3。
第一份的行数(178)与字节数(15089)自相矛盾,末尾挂残缺标签。**那份报告连 `rule_id` 带数字一起编造,而命令、退出码、字节数一应俱全。**

**唯一挡住它的是「恰好收到两份冲突报告」这个偶然。** 只收到第一份不会去查。

**规避**:凡 agent 报告中的关键数字与条目名,**合并/写回前必须回读实际产物验证** ——
①判定分布计数 ②被点名的 `rule_id` 是否真在文件里 ③行数与字节数是否自洽。

## 四 · 台账里的计数会过期,且会多道传递无人复核

**实证(同一份文件三处)**:`CONSOLIDATED.md` §4.4① 写「十二锚中十一条须落值」,只扣了 `BSM-0063`,
**漏扣 `BSM-0393`(它自己在 §4.2 就列了)与 `BSM-0547`(它自己在 §5.2 记了改判)**;正确是 9 条落值 3 条保持。
该错误传播链:**台账 → 我的任务书 → 上一 agent 落进 evidence → 下一 agent 从 evidence 读取当期望值**,四道无一复核。
同文件 §4.3③ 的 S1 计数、§5 D-01 的断言各是第二、三处。

**规避**:
1. 台账内任何计数断言,**同行附取数命令与命中数**
2. 一处数字变更后,**全文自扫同族数字**(本轮 `PGM-0092` 由边界升钱路,牵动 §4.4①/§4.3③ 两处未回改)
3. 转述他人报告的数字时,标明**来源是实测还是转述**

## 五 · 判定类工作的三条有效方法

1. **相邻行已填、本行空着 = 漏判的硬证据**
   实证:`BSM-0758` 相邻八行全填、只此一行空,且与已填的 `BSM-0610` 是同一规则两处登记;
   `BSM-0391`/`0392` 夹在已填的 `BSM-0390`/`0395` 之间;`BSM-0133` 的同句 `BSM-0552` 已填。
2. **口径靠同域反证固定,不靠口头约束**
   实证:`BSM-0180` 判钱路的理由锁定在「记收款人」而非「列出支付通道」,
   靠同域 `BSM-0112`/`BSM-0158`(列了通道但不记收款人)判非钱路作反证。
   若用「列出通道」作理由,这两条必须一并翻。
3. **验收锚要在开工前定,且要能机检**
   实证:S2 片给了八条已知假阴性作锚,判完逐条点名确认全中;
   S5/S6 片无锚,agent 主动标注「本片判定质量无机械自检点」为弱点。

## 七 · 分层豁免不可信(G-1 实证)

分层设计耗**五轮抽样、四次判据修正**,只省 300 条,而抽样**两次失败**:
第一次 n=40 首轮即命中假阴性;第二次覆盖率 16 倍落差下「0 命中」87% 概率是错过。
改全判后实测:**S5 三域、S6 四域上轮抽样命中率均为 0,全判各判出 5 条与 3 条钱路,抽样漏了全部。**

**判据**:豁免的举证成本 > 全判成本时,直接全判。全判没有「为什么这些可以不看」的举证负担。

## 八 · 结构性发现(须另轮处置)

| # | 发现 | 影响 |
|---|---|---|
| 1 | **G-1 只防假阴性不防假阳性** | 判定面是「该填没填」的 784 条;已填 340 条从未按判据复核。仅 S6 四域实测:已填 25 条中 14 条疑过填;另 7 条疑 R9 批量误填(`BSM-0016`/`0464`/`0422`/`0082`/`0497`/`0511`/`0523`)。**钱路总数两个方向都失真** |
