  + - **退租结算**：触发/转交退租与费用结清流程（租金、物业、能源、押金等以合同履约域为准）；

  + 4. **退出完成**：退租结算完成后，招商侧商户合作状态更新为退出/结束类状态，黑名单规则仍可拦截再入。
