## 边界条目（需编排层裁）

### 边界-1 `BSM-0161`（bar）核销顺序与「一家一份」权益发放

原文关键句：`一张通票覆盖几家酒吧，就为每一家各发一份独立的入场权益与赠酒权益，一家一份、互不占用`

- **判钱路一方**：`BSM-0163`（已填钱路）定「通票赠酒核销后由平台按内部结算价与出品酒吧结算——核销一杯结一杯」。本条决定同一张通票产生几份可核销赠酒权益，即直接决定平台承担的赠酒成本笔数上限 = 决定金额（§2.1「决定金额：怎么算、算多少、上下限」）。
- **判非钱路一方**：本条主语是履约标的与核销顺序，金额由 `BSM-0163` 的内部结算价定；按已裁 `BSM-0661`（决定兑换标的 → 非钱路、钱路前置）同构。

两个先例都成立且指向相反，不硬判。若裁非钱路，`conflict_summary` 须按 `BSM-0661` 处理方式注明是 `BSM-0163` 的钱路前置。

### 边界-2 `PGM-0227`（bar）酒吧经营牌照登记主体

原文：`酒吧经营牌照登记在实际经营法律主体名下，娱乐平台公司不会因持股自动成为牌照主体。`

- **判非钱路一方**：法律主体身份定义，按已裁 `BEQ-0074`「经营主体四层」先例（定义载体，指派的是引用它的条）。
- **判钱路一方**：同段瀑布的相邻行 `PGM-0224`（维护供货库存并收取供货货款）、`PGM-0225`（收取场地租金、物业等资产相关收入）、`PGM-0228`（未经审批的内部协议不产生场地使用效力、也不得据以入账）、`PGM-0229` 全部已填钱路，只有 `PGM-0226`/`PGM-0227` 空着；整段起句「酒吧股权、牌照、场地和资金必须分别记录」的意图正是防止收入错记到娱乐平台公司名下，即决定营业收入在谁名下入账。

同段落 `PGM-0226` 因含可配比例（80%／20% 决定分红分配比例）已判钱路，`PGM-0227` 无比例、只有主体身份，故单列。

### 本片新发现、PLAN §5.8/§7 未登记的重复关系

以下五组为本片判定时发现，PLAN 的完全重复扫描与 §5.8 三对清单均未覆盖，属 §7.2「语义重复只能靠判定者在同一 shard 内识别」的实证：

1. **供应合同三种模式：四联同文，不是一对。**
   `BSM-0202`（supply，PLAN §2.4 已裁钱路，§6.1 并入 S4）、`BSM-0501`（cross-domain，S4，§2.5 十二条之一）、**`BSM-0222`（supply，本片）**、**`BEQ-0049`（supply，本片）**。四条同义，本片两条按已裁口径同裁钱路。PLAN §5.8 只登记了 `BSM-0202`/`BSM-0501` 一对，漏了本片这两条。

2. **`BSM-0224` / `BEQ-0051`（supply）物品大类枚举**——语义重复对，成对同裁非钱路。

3. **「一体机只能卖本店单店门票、不得卖综合体通票」跨片三联。**
   `BSM-0063`（ticketing/S2，PLAN §2.5 十二条假阴性之一，**必判钱路**）、`BSM-0132`（terminal/S5，`value_flow` 仍为 `NOT_STATED`）、**`BSM-0149`（bar，本片）**。三条同义。本片依 `BSM-0063` 先例判 `BSM-0149` 钱路：售卖主体/渠道限定决定这笔票款归谁——`BSM-0629`（已填钱路）明写「单店门票……票款当场计为该酒吧商户对娱乐平台公司的应付款」，通票收入则归项目公司，故限定卖哪种票即决定归属。**须与 S2、S5 跨片同裁。**

4. **`BSM-0211`（supply，本片）/ `BSM-0156`（bar，已填钱路 `按杯销售按标准出酒量扣减库存，超出标准部分记为损耗。`）**——同一规则两处登记，一处已填、一处空着，是账本内部的漏判直证。本片判 `BSM-0211` 钱路。同族还有 §7.1 的 `BSM-0179`/`BEQ-0033`（见下节）。

5. **最低消费配置维度：五联，跨四片 + 两条哨兵。**

## 判据冲突（须编排层裁，本片不自行解决）

`BSM-0547`（governance/S1）原文：`后台配置只能承载规则，不能改变三份最高解释权 HTML 的业务口径；票务规则和商户消费业态规则不得混用。`——PLAN §2.5 钉死**必判钱路**。
