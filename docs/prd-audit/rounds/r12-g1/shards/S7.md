## 边界条目（需编排层裁）

**BSM-0195（service）** —— 「点单员代客下单、向客人出示收款码、确认收款和点完成履约都是现场操作，一律在公司工作手机上办理，不在自己的私人手机上办。」

- 判钱路的理由：「向客人出示收款码…不在自己的私人手机上办」在实质上约束了这笔钱经哪个载体收，等于排除「钱先进员工个人账户」，属 §2.1「决定方向：经谁收」。同片 BSM-0180「支付方式…现金（记收款人）、POS（记流水号+收款人）」已被 PLAN §2.5 列为第 13 条假阴性候选，理由同为「决定经谁收」。
- 判非钱路的理由：本条约束的是**操作设备与操作场所**，不是收款主体；订单收款码的收款主体由别处条目指派（服务费公司代收口径在 service/finance 域另有条目）。按 §2.2「权限/操作约束」应落 `permission`。
- 不硬判的原因：两侧都能自洽，且裁定结果会连带影响同族的 BSM-0194（本片，已判非钱路）与其他域的工作手机类条目。

## 验收锚自检

**BSM-0420 判定 = 钱路。** 建议值取原话「系统会把它记成「欠主理人、以后要还的一笔款」，按约定规则（手动释放、下期释放或年度末释放）再返还给主理人」。判据双命中：决定方向（本期暂扣 → 按规则返还给主理人）+ 决定归属（记为平台对主理人的负债，非平台收入）。该条 48 词钱字样表零命中（`款`/`暂扣`/`释放`/`返还`/`欠` 均不在表内），与 PLAN §5.2 的第二实证一致。

同族的 BEQ-0121 是 BSM-0420 的枚举镜像（「留存待释放 / 已释放…发还给主理人」），按 §5.8 成对同裁一并判钱路——**该对属机检捞不到的语义重复**（措辞不同、跨 html_file）。
