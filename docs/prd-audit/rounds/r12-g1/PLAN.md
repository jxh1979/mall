## 2. 判据

### 2.1 填写条件
**该条规则本身决定或改变某笔钱的金额、方向或归属。**
- 决定金额:怎么算、算多少、上下限
- 决定方向:谁付给谁、经谁收
- 决定归属:算谁的收入 / 成本 / 基数 / 账期

### 2.2 判 `NOT_STATED` 的情形
| 情形 | 先例 |

### 2.3 积分类先例(整类适用,不逐条判)
**积分不是钱。** 积分的获取、扣减、兑换、有效期、适用哪套规则 → `NOT_STATED`;积分的**成本承担与结算** → 钱路。

依据:`value_flow` 口径逐字是「某笔**钱**的金额/方向/归属」。链路是 积分 → 虚拟券 → 按内部结算价与商户结算,**第三步才是钱**。纳入会让积分/成长值/权益整条链变钱路,口径失去区分力。

分界:`BSM-0599`(决定用哪套积分规则)非钱路;`BSM-0661`(决定兑换标的)非钱路;「积分发行成本由谁承担」「兑换补偿按内部结算价与商户结算」钱路。前两条 `conflict_summary` 须注明是钱路前置。

## 5. 方法论(八条,逐字保留)

**5.1 抽样不可自证** —— 「单次抽样已经失败一次,再抽一次通过也只是运气。」本轮已四次出现「测量方法失效被读成通过」,抽样是第五类。

**5.2 钱字样正则是「有钱字样」检测器不是「定义钱路」检测器** —— `BSM-0392`/`0393`/`0394` 同一张收入归属表连续三行、语义同构,正则只捞到含「服务费」的那条。第二实证 `BSM-0420`:非表格型、48 词扩展表一个不命中(`款`/`暂扣`/`释放`/`返还`/`欠` 全不在表内)。

**5.3 等距抽样 `step = N // k` 有尾部盲区** —— `N=630, k=40` 时只走到 idx 585,尾部 44 条永不可能抽到。须 `idx = round(i*(N-1)/(k-1))` 覆盖首尾。

**5.4 样本量必须与基数挂钩** —— 覆盖率落差 16 倍(finance 71% / governance 4.4%);按 finance 命中率反推,governance 抽 5 条恰好全错过概率约 87%。改 `max(5, ceil(n×15%))` 后 governance 5→17 才抽到 `BSM-0547`。

**5.5 等距索引集不嵌套** —— 样本量 +19 实际新增待判 **30 条**。工作量按待判条目计,不按样本量差。

**5.6 `BSM-0402` 拆列正确正例** —— `value_flow: NOT_STATED`(状态枚举无钱路)、`approval` 逐字落「锁定后补录须上级审批。」。说明什么叫 `value_flow` **该**空:一条规则可以既有实质约束、又在 `value_flow` 上正当为空,只要该约束属于别的要素列。

**5.7 `BSM-0371` vs `BSM-0750` 同主题不同判** —— 定义归集边界的判钱路(决定每笔钱归哪个账期),只说批次频率的不判。

**5.8 重复登记条目成对同裁** —— 三对:`BSM-0670`/`BSM-0773`(逐字同文,机检可发现)、`BSM-0202`/`BSM-0501`(语义重复,机检不可)、`BSM-0547`/`BSM-0677`(语义重复,机检不可)。**三对中只有一对能被完全重复扫描捞到。**
