## 12. 复核 NEEDS_FIX 返工（B-2，2026-08-07/08）

复核唯一返工项：三裁②废除 51% 门槛后，账本 `PGM-0243` 的 **`preconditions` 列**仍留着已废除口径。

**漏网原因**：三裁的账本同源重取用的是与 HTML **完全一致**的替换串 `公司持股超过 51%（业务参数，…）的商户视同公司自有`（`51%` 前后带空格）；而该格是早期抽取时写下的**去空格改写版** `公司持股超过51%的商户视同公司自有`，既不含括注、也没有空格，故整行替换零命中。**同源算法只能追平「与 HTML 逐字同源」的格，追不平历史抽取时被改写过的格**——这正是 `SYNC1-03` 登记的镜像列问题的一个实例，但本格性质不同（见下）。
