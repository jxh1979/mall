### R14-SR-09 · B · P1 · 票务积分发行成本的收款方 —— 本分片最高优先级

**五条件自证**（request §5.2）：①属金额去向与责任主体的规则选择 ✓ ②取证已完成（三份 HTML 宽正则 + 台账 + R13 diff，见下）③现有权威来源无唯一答案 ✓ ④存在两个合理方案 ✓ ⑤用户回答创造新业务事实（是否把消费积分侧的收款方规则扩到票务侧）✓

**两处查证结果**：
- **决策台账**（`business-decision-ledger.md`，读到底含 §G 与全部追加块）：`DEC-R8-87`（:1932）原文**只裁扣除机制与承担方，无收款方**；`DEC-R3-2026-08-04-34`（:1017）「积分发行费 ＝ 转为可用的积分数 × 全国统一积分发行单价；收款方为全国积分结算中心，其不是独立公司时为顶层平台公司」——该式的计费基数是「**转为可用的**积分数」，即 ENUM「有效消费与冻结」条定义的**商户消费积分**，票务积分不走"退款期冻结→转为可用"这条路（ENUM「票务人次计算」条：票务积分按已核销的张／人次计）。

### R14-SR-08 · B · P1 · 跨域组合通票酒吧部分的门票综合服务费计费基数

**五条件**：①比例与计费基数的规则选择 ✓ ②取证完成 ③HTML 无唯一答案 ✓ ④两方案 ✓ ⑤用户创造事实 ✓

**两处查证**：决策台账宽正则检索「计费基数」「最终选中价」「综合服务费」全部落点——只命中 BEQ-0018 引用，无独立裁决；canonical findings 无对应条目。

**证据**：ENUM「门票综合服务费」条（BEQ-0018）原文「娱乐平台公司另按每张门票的比例或固定金额收取服务费，两种方式互斥，并可设置月度封顶。**按比例收取时，计费基数一律是该张票订单上保存的最终选中价（客人实付价），不使用基础价或动态价，也不先扣第三方渠道费用**……酒吧通票和跨域组合通票中的酒吧部分**也可按生效规则收取，但不得封顶**。」——计费基数句写在单一酒吧门票语境内，跨域句只说"按生效规则"，未复述基数。本 PRD 全文「最终选中价」「计费基数」**零命中**（EV-SR-13）。

**代实数（跨条算术）**：跨域组合通票售价 200 元（酒吧业态价 120／游乐 60／餐饮 20，不打折），第三方渠道售出，通路费 1.20、销售渠道费 10.00、积分发行成本 4.00，G＝15.00，费率＝出厂默认 2000bps（本文 `:282`）。

```
①-a 200.00 − 1.20 = 198.80
①-b 198.80 − 10.00 = 188.80
①-c 188.80 −  4.00 = 184.80
②   酒吧 184.80×60% = 110.88 ｜ 游乐 55.44 ｜ 餐饮 18.48   （Σ = 184.80 ✓）
④   读法甲 F = 20%×200.00 = 40.00 → P = 110.88 − 15.00 − 40.00 = 55.88
     读法乙 F = 20%×110.88 = 22.18 → P = 110.88 − 15.00 − 22.18 = 73.70
     两读法每张票差 17.82 元，全部落在酒吧商户与娱乐平台公司之间
```

**负池反例**（读法甲 + 不得封顶）：同一票改为酒吧业态价 20／游乐 180 → 酒吧份额 ＝ 184.80×10% ＝ 18.48；F ＝ 20%×200 ＝ 40.00 → P ＝ 18.48 − G − 40.00 **< 0**。本文 `:309` ③ 确认负池会"向酒吧追回"，而 `:105` 的事前试算闸要求"第一段应分合计不超过**最低可能**池金额"——最低池金额为负时任何正的第一段固定额都过不了闸，该票种的第一段配置**永远无法生效**。HTML 对跨域组合通票的酒吧部分**既写"不得封顶"、又未写基数下限或兜底**。

**最小决策面**：HTML 明确了单一酒吧门票的基数；未明确跨域组合通票酒吧部分的基数、以及基数取整单时酒吧份额被穿透的兜底。候选：甲＝整单最终选中价（须同批裁定负池兜底）；乙＝酒吧域份额（须裁定与单一酒吧门票基数不同是否可接受）。change_target 视裁决落在 HTML（C）或 PRD（A）。

### R14-SR-07 · B · P1 · 事前试算闸缺上游配置变更的回溯触发

**最小决策面**：HTML 明确"试算不通过的配置不得生效"；未明确"上游配置变更是否须回溯试算全部在效第一段配置、不通过时如何处置"。候选：甲＝任何影响池金额的配置（服务费率／渠道费率／G 规则／价格档）转正前须对全部在效第一段配置重跑试算，不通过则拒绝转正；乙＝允许生效，超出部分按 `:107` 归娱乐平台公司承担并自动登记短期经营激励；丙＝上游配置也纳入通告期。三案对运营节奏与商户预期影响不同，须用户裁。
