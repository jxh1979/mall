## 用户裁决（B 类弹窗 12 项，裁决 16–27）

16.（B-01 / SO 推断 1）渠道回传永久丢失：**丙——认定该场景不存在**，规则维持现状（收不到回传不能点完成、不设人工放行）。选项已披露前提风险（需渠道 SLA 保障）；日后若实际发生，按新业务事实重开裁决。
17.（B-02 / R14-SO-05）管理费变更前通告：**甲——在 HTML 销售提成条补通告规则**（对象、提前时长、留痕），服务点单经「一律比照」自动继承。change_target=HTML，转 C 类草案（HTML 修订轮起草后逐句批准）。
18.（B-03 / R14-SO-04）服务点单完成后退款：**乙——存在有限的撤销情形**（如误点完成、渠道撤单），需新增第五态或撤销动作；与「四态为全集」「已完成为终态」两条硬约束冲突，状态机、留痕、薪资冲正、§13 验收随之重写。change_target=HTML+PRD，列为修复轮影响面最大项。
19.（B-04 / INF-TK-01）票务退款期：**甲——退款期＝场次结束**（与场次终结制对齐）；多人票按整票计；场次结束后经 U 盘密钥例外退款的，已转可用积分按**追偿**处理。裁决 5「预估扣＋差额冲正」的转可用锚点就此落地。
20.（B-05 / R14-TK-08）票务策略状态机：**乙——不设独立状态机**，复用票种 4 态（草稿/上架/暂停/归档）；「待启用」「已结束」按生效时间派生、不存储。连带：R14-TK-09 出处声明按此修正；R14-CF-07（E-36）目标状态确定＝按 4 态对应，无需新增枚举。
21.（B-06 / INF-TK-02）域内通票积分发行成本：用户核验 HTML 现文后确认——**「在域间拆分之前从整单扣除且只扣一次」的提前扣除机制已写入 ENUM L48 / BSM L748，域内通票照此执行**（扣除后剩余全归该域＝该域主管公司实际全额承担）。唯一缺口是积分成本句缺「域内通票同样适用」镜像半句（渠道费句已有），转 C 类机械补写。
22.（B-07 / R14-SO-11）价格术语：**乙——加同一性声明**「服务售价＝本表固定价格」，PRD §3.1 与 HTML（BSM L1120 / ENUM L282 处）同批各加一句，不做全文改名。R14-CF-04（管理费上限校验）修复的分母就此确定＝服务目录项固定价格。
23.（B-08 / R14-TK-12）刷新间隔默认 15：**甲——追认「出厂默认 15 秒」逐句批准写入 HTML**（C 类）；契约 E-25（R14-CF-06）按「5 秒为单位、5–60」修正枚举，默认值 15 在其内。canonical FINAL-11 随之有唯一目标状态；其 file 列补登本 PRD 6 处落点。
24.（B-09 / R14-TP-08）支付两行：**甲——合并为一行**，以 HTML「聚合支付」条的回流字段为准；「支付/渠道（非团购）」行删除并入。
25.（B-10 / SO 推断 3）零份额分账：**甲——0 元照样生成分账记录、薪资单照列 0 元行**，全链路可追溯。
26.（B-11 / INF-TP-01）安检环节设备（X 光）：**乙——矩阵补行但只登接入关系**，回传内容留空标「待定」，不自拟回传字段、不凭空创造个人信息采集面。
27.（B-12 / R14-TP-11）第三方片段留存分类表：**甲——把合规文档 §6.1 分类留存表升为业务权威**，逐句批准补进权威 HTML（C 类）；PRD :220 的依据在 HTML 落地后改标正式条目名。
