## 1. 文档定位

本文档按业务动作拆解会员忠诚度与储值能力，回答“消费怎么变积分、积分怎么算等级、积分怎么兑换、签到生日怎么奖励、客人怎么充值消费余额、怎么开通付费会员”。会员体系与票务核销、酒吧消费、礼品库存、财务对账连通。

客人账户与员工/商户账号体系完全隔离（见客人端 PRD）。

## 2. 目标

- 把客人的每一笔消费按后台规则转成会员积分与会员等级成长。
- 用“两本账”分别管理会员等级与可兑换积分，互不串扰。
- 支持积分兑换**虚拟券**（券再核销领取实物/折扣/权益），兑换当时不扣库存、券核销领取实物时才按库存约束扣减。
- 支持连续签到、生日加倍等忠诚度玩法。
- 支持客人充值余额、消费扣余额（储值预付卡）。
- ~~支持客人开通、续费、取消付费会员订阅。~~ **（已废止 2026-07-18）**

## 3. 积分两本账（核心口径）

会员积分分两本账，互不影响：

| 账 | 用途 | 增减规则 |
|---|---|---|
| **成长积分** | 算会员等级 | 消费确认（pending→confirmed）时与可用积分**同时增加**、金额同源；**只增不减**、不受兑换影响；仅到期清减后才可能导致等级下调 |
| **可用积分** | 兑换消耗 | 消费确认时随成长积分**同时增加**；兑换时**仅扣可用积分**、成长积分不动；扣减**不影响**会员等级 |

- 会员等级：按累计成长积分达门槛**自动升级**；档位与门槛以后台规则为准；成长积分仅在到期清减后才可能下调等级。
- 入账时机：一笔消费从待入账转为已确认（pending→confirmed）时，**可用积分与成长积分同时按同一入账金额增加**；兑换消耗**只扣可用积分**、成长积分保持不变。
- 到期清减：成长积分按自然年清零，或按后台配置的有效天数清零。

## 4. 积分获取

- **有消费就给**：买票入场、订卡、酒吧消费等都计积分。
- 计分方式（后台可配，可组合）：按消费金额 / 按核销张数（购票一次送固定值）/ 按打卡签到（一次给固定值）/ 按生日加赠 / 按活动。
- 获取渠道：会员关联微信/支付宝后，在场内用微信/支付宝付款自动累计积分；POS、现金等其它付款方式可现场录入会员号累计。
- **按核销张数确认**：购票积分按实际已核销张数比例确认（核销几张算几张，未核销/过期/退款不计）；退款按已确认份额冲减。
- 积分明细类型：获取、扣减、兑换消耗、过期、调整；每笔关联触发它的业务单据。

## 5. 积分兑换（虚拟券模型，2026-07-18 现行）

- 积分只兑**虚拟券**、不直接兑实物；**兑换当时不减可售库存**——实物/服务券在发券当场从可用库存**预占（冻结）一件**、不减总库存，发券数量受可用库存约束以防超发（折扣券不涉及库存、不预占）。
- 券分三类核销：
  - ①**商户折扣券**：到对应商户抵扣。
  - ②**店内实物或服务**：发券时从可用库存预占，到店由店员核销领取时**把预占转为实际出库**、按内部结算价与承接商户结算；**券过期或作废则释放预占、放回可用库存**。（预占机制防止券超发实物库存。）
  - ③**平台或外部合作伙伴**：到平台服务台或外部合作伙伴处核销。
- 客人「**我的券包**」按『可用 / 已核销 / 已过期』分组查看名下所有券；**每张可用的券可点开（或有「使用」按钮），进入可核销使用或转赠该券的界面**。
- 券可设有效期、**过期不退**；**券支持转赠他人**——**券是否可转让在后台生成券种时可配，默认可转让，关闭则该券种发出的券不可转让**。
- 换实物的券若实物缺货，可退回成积分（兑换时即向客人说明）。
- **券对应的内部成本价对客人和店员均不可见**，仅后台被授权角色可见。
- 兑换发放有状态（待发放、已发放、已取消、异常）。
- 区分口径：**积分本身仍不支持会员间转赠**（积分绑定本人）；可转赠的是兑出的**券**，二者不同。

## 6. 忠诚度玩法

- **连续签到**：客人每日签到记连续天数，按连续天数阶梯奖励积分；断签重置。
- **生日加倍**：生日当天或生日月消费积分加倍（与等级倍率叠加）。

## 9. 状态枚举（业务口径，最终以后台配置为准）

- 兑换发放：待发放、已发放、已取消、异常。
- 券状态（我的券包分组）：可用、已核销、已过期。
- 券类型：商户折扣券、店内实物或服务券、平台或外部合作伙伴券。
- 储值账户：active（正常）、frozen（冻结）、closed（关闭）。
- 储值流水：充值、消费、退款、调整。
- 付费会员：active（有效）、expired（到期）、cancelled（取消）。
- 积分明细：获取、扣减、兑换消耗、过期、调整。
- 积分过期：成长积分按自然年清零，或按后台配置有效天数清零。

### 积分兑换商户虚拟券的承接时点（2026-07-28 / POINTS-VOUCHER-ACCRUAL-001）

- **已确认：不采用先冻结、后核销才计承接。**
- 消费者以积分兑换商户虚拟券时：
  1. 在**兑换成功时点**扣减消费者可用积分；
  2. 同步按规则记录该商户/成本主体的积分成本或承接（入账时点=兑换时点，而非到店核销时点）；
  3. 券的核销只消耗券权益本身，**不再作为“承接积分是否入账”的开关**；
  4. 若券过期、作废、退回导致成本应回退，按券生命周期做冲回/调账，不得把承接长期停留在“冻结待核销”状态来代替冲回规则。
- **未决**：净积分计价/每分金额（另案确认）。
