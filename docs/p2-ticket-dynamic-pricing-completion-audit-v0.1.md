# P2-C 票务动态定价规则容器完成审计 V0.1

## 1. 审计结论

P2-C 已完成可编码闭环并完成订单接入升级：动态定价规则可创建、发布、模拟、持久化、审计和权限控制；草稿规则只模拟，已发布且匹配的规则会影响正式下单价格，并在订单中保留基础金额、调整金额和命中规则。

## 3. 验收覆盖

- 创建动态规则默认进入 `draft`。
- 发布后状态进入 `published`。
- 模拟时按日期、渠道、条件 JSON 和优先级匹配规则。
- 命中规则时返回基础价、调整额、最终价和规则 ID。
- 未命中规则时最终价等于基础价。
- 已验证正式下单仍使用现有票价逻辑，不受动态定价模拟影响。
- 接口要求幂等键。
- 接口使用精确权限，不复用老的票价变体权限。
- PostgreSQL JSONB 条件和附件数组可读写。

## 4. 对抗式审计

| 发现 | 结论 | 处理 |
| --- | --- | --- |
| 发布规则是否会误改正式售票价 | 不会，本期未接入下单路径 | 文档和测试均明确 |
| 动态条件是否可能解释歧义 | 有风险 | 本期只支持键值完全匹配，复杂表达式后置 |
| 多规则冲突 | 已处理 | 按优先级和更新时间排序 |
| 价格越界 | 已处理 | 使用最低价/最高价保护 |
| 权限过粗 | 已处理 | 独立四个权限 |
